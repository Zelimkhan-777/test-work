# The Art — интернет-магазин картин

Тестовое задание на Vue 2 (Options API). В приложении реализованы поиск по названию и автору, асинхронное состояние покупки, сохранение корзины в `localStorage`, модальная карточка товара и адаптивная вёрстка до 360 px.

## Требования

- Node.js 16.x
- npm 8.x (поставляется с актуальными версиями Node.js 16)

## Запуск

```bash
npm install
npm run dev
```

После запуска приложение будет доступно по адресу `http://localhost:8080`.

## Production-сборка

```bash
npm run build
```

Оптимизированная сборка появится в каталоге `dist`. Для локального просмотра можно использовать любой статический HTTP-сервер.

## Команды

- `npm run dev` — dev-сервер без автоматического открытия браузера;
- `npm run serve` — dev-сервер с открытием браузера;
- `npm run lint` — проверка Vue/JavaScript и конфигурации ESLint;
- `npm run build` — production-сборка Webpack.

## Реализация

- Vue 2.7, Options API;
- компоненты `SiteHeader`, `ProductCard`, `ProductModal` и `SiteFooter`;
- Webpack 5 и Babel;
- ESLint 8 с правилами Vue;
- без UI-библиотек и внешних runtime-зависимостей;
- локальные изображения и WOFF2-шрифты, поэтому интерфейс не зависит от доступности сторонних CDN;
- семантическая разметка, состояния фокуса и поддержка `prefers-reduced-motion`;
- адаптивная сетка: 4 / 2 / 1 карточка в ряд.

Ссылка на исходный макет: [Banki.shop в Figma](https://www.figma.com/file/6LxPDEsauEGanhR2nDW68X/Banki.shop?node-id=0%3A1).

Репродукции «Рождение Венеры», «Тайная вечеря» и «Урок анатомии» загружены из Wikimedia Commons; произведения находятся в общественном достоянии. Изображения галереи — локальные детализированные фрагменты, подготовленные скриптом `scripts/generate-gallery-assets.ps1`.
